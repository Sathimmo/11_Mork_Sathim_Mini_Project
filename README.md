# Student Academic Manager (Swift CLI)

A command-line application built in Swift to manage students, academic scores, averages, grades, and class reporting.

---

## Prerequisites
* **Swift 5.x or newer** (comes pre-installed with macOS Xcode Command Line Tools, or installable via Swift.org on Linux).

## How to Run

1. Open your terminal and navigate to the directory where your source file is located.
2. Save the code into a file named `main.swift`.
3. Compile and execute the file directly using the Swift runner:
   ```bash
   swift main.swift
